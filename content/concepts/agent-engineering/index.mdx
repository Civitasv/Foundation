# 从图灵机到大模型

## 摘要

大语言模型把许多原本分别建模的任务放进了同一种交互方式：给出一段文字，再生成一段文字。解释这种通用性，需要同时考察学习目标、表示方法和计算条件。本文以计算理论、神经语言建模、预训练与规模化研究中的代表性工作为线索，讨论规则如何从人工编写转向数据学习，语言预测如何支持任务迁移，以及数据和算力为何成为模型设计的一部分。本文的判断是，大模型的形成依赖这些条件的共同作用；其中任何一项进展，都不足以单独解释模型能力。文章最后讨论语言模型进入 Agent 系统后，预测质量与执行可靠性之间仍然存在的距离。

## 引言：通用性究竟来自哪里

让一个程序翻译句子、归纳文章，再根据报错修改代码，过去通常意味着准备几套不同的处理流程。大语言模型使这些任务可以共用一个模型，任务要求则写进输入文本。这种变化值得解释：为什么一个以语言预测为训练目标的系统，能够被用于这么多不同的工作？

沿年份排列发明，很容易把答案写成一条顺理成章的进步史：先有计算机，再有互联网，随后数据增多、网络加深，大模型便出现了。可这条叙述省略了最难的部分。数据为什么能被利用？训练时学到的东西为什么能迁移？增加计算投入究竟改善了什么？这些问题之间有关联，却不能彼此替代。

本文是一篇面向入门读者的叙述性综述，选取从可计算性研究到 2020 年代初预训练语言模型的代表性文献，按问题组织比较。这里重点讨论通向大语言模型的一组技术关系，不试图覆盖完整的人工智能史，也不评比最新模型。符号推理、搜索和其他统计学习方法有各自延续至今的研究脉络；以下选材不意味着它们最终都被神经网络取代。

## 可计算性与学习：两种不同的通用性

图灵机给出了讨论计算的一种精确语言。它用有限的控制状态、可读写的纸带和转移规则，描述一个计算过程如何逐步执行。当一台机器的规则可以编码成另一台机器的输入时，同一个装置就能模拟不同的计算过程，这便是通用图灵机的关键思想。[Turing，1936/1937](https://londmathsoc.onlinelibrary.wiley.com/doi/abs/10.1112/plms/s2-42.1.230)。

这里的“通用”有明确含义：给定适当的程序，机器可以执行相应的可计算过程。至于程序从哪里来，理论并没有替设计者回答。排序算法的步骤可以由人完整写出；要判断一句话是否在讽刺，规则就难以穷举。同一个词在不同语境里可能表达相反的态度，列出更多关键词也未必能解决问题。

机器学习让程序的一部分行为可以通过学习获得。设计者选择模型、输入表示和评价目标，训练过程再利用数据或交互经验调整模型。这里的“经验”可以有不同来源，学习方式也随之不同。

Rosenblatt 的感知机研究了如何学习分类；按今天常见的监督学习方式，训练样本提供正确类别，模型根据分类错误调整权重。Samuel 的跳棋程序则结合搜索、局面记忆与评价函数的学习，利用搜索回传的评分等信息改善对局面的判断，体现了强化学习的早期思想。它并不依赖人为标注每一步的最佳走法，也不能简单概括为赢了奖励、输了惩罚。两者都从经验中学习，但学习所依据的反馈不同。[Rosenblatt，1958](https://doi.org/10.1037/h0042519)，[Samuel，1959](https://ieeexplore.ieee.org/document/5392560)。

以文本分类为例，可以先把词频转换为数值特征，再学习特征与类别之间的关系。模型中可调整的数值称为参数；损失衡量预测与目标的差异；训练据此调整参数，推理则用训练后的模型处理输入。真正困难的是泛化：模型必须在未见过的样本上仍然有用。记住训练文本及其标签，并不能证明它学会了判断新的文本。

于是，通用计算与通用模型落在两个层次上。前者讨论同一计算装置能执行哪些程序；后者讨论同一组学得的参数能适应哪些任务。大模型仍由程序实现，也仍在有限的时间和内存中运行。它扩展的是可由数据学得、可在任务间复用的行为范围。这个区别也解释了为什么图灵机适合作为理论起点，却无法直接解释大模型的实际能力。

## 表示学习：模型怎样利用没有见过的组合

学习能否奏效，很大程度上取决于输入如何表示。若文本只被表示为词频，“我喜欢你”和“你喜欢我”就会得到相同的表示，句子中谁喜欢谁的信息随之丢失。人工特征可以很有效，但也把模型能利用的信息限制在设计者预先选出的范围内。表示学习尝试让模型自己形成有助于任务的中间表示。

神经网络提供了一种可训练的表示方式。一个常见的前馈层写作：

<Equation label="前馈层的表示变换">

**h = σ(Wx + b)**

</Equation>

x 是输入向量，W 和 b 是可学习的权重与偏置，σ 是非线性函数，h 是变换后的表示。多个层可以围绕同一个损失共同训练。反向传播沿计算图应用链式法则，计算损失对参数的导数；优化器再利用导数更新参数。Rumelhart 等人的工作展示了这种训练方式如何形成内部表示。[Rumelhart 等，1986](https://www.nature.com/articles/323533a0)。[向量](/concepts/vector/)与[矩阵](/concepts/matrix/)两章会进一步解释这里的数值对象和变换。

多层可学习表示构成了深度学习的基本做法。不过，要理解它在语言上的价值，稀疏性比“层数更多”更值得先看。传统 n-gram 模型根据有限窗口内的词序列估计续写概率。随着窗口变长，可能的组合迅速增多，语料却不可能包含每一种说法。模型需要把在某些句子上获得的经验用到其他句子上。

Bengio 等人的神经概率语言模型同时学习词的连续表示和序列概率，使相近表示能够共享统计信息。它把“如何表示词”与“如何预测词”放进同一个学习问题。[Bengio 等，2003](https://www.jmlr.org/papers/v3/bengio03a.html)。这种把离散项映射为向量的做法称为嵌入。向量的每一维不必都有可命名的语义；有用的关系可以分布在多个坐标中。

例如，一个模型在“猫在沙发上睡觉”中学到的规律，可能有助于处理“狗在沙发上睡觉”。这是共享表示的直观例子，具体能否迁移仍取决于训练数据和目标。表示学习减轻了逐条记忆组合的负担，却没有消除数据选择的影响。哪些差异会被保留，哪些差异会被忽略，仍由训练过程决定。

## 语言预测如何成为可复用的训练任务

表示学习需要目标。对于语言，一个可行的目标是根据已有文本预测后续内容。Shannon 对消息源和英语统计近似的研究，已经展示了用概率描述符号序列的思路；熵则刻画了消息源的平均不确定性。[Shannon，1948](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf)。这种形式化让语言中的不确定性可以被估计和比较。

现代语言模型通常先把文本切分为 token，它可能是词、子词或其他编码单位。对于自回归模型，序列概率可以分解为：

<Equation label="自回归序列概率">

**Pθ(x₁, …, xₜ) = ∏ᵢ₌₁ᵗ Pθ(xᵢ | x₁, …, xᵢ₋₁)**

</Equation>

其中 xᵢ 是第 i 个 token，θ 是参数。模型根据前文估计下一个 token 的概率分布，训练时通常通过降低真实后续 token 的负对数概率来调整参数。文本本身就提供了预测目标，这使大量没有人工任务标签的语料也能用于训练。这类从数据自身构造监督信号的方法称为自监督学习。[概率分布](/concepts/probability/)一章介绍理解这一目标所需的基础。

语言预测之所以值得投入，还在于它对上下文提出了丰富的要求。补全一句话可能需要局部语法，也可能需要知道代词指向谁、前文讨论什么，甚至需要利用事实知识。这里可以作出一个解释：一个覆盖多种文本的预测任务，有机会训练出能被其他任务利用的表示。但训练目标本身并不构成这些能力一定出现的证明；迁移效果需要下游实验来检验。

预训练与微调把这种复用落实为训练流程：先在广泛数据上学习，再用目标任务的数据更新参数。GPT 与 BERT 是两种有代表性的选择。GPT 使用生成式语言预训练；BERT 通过包括掩码语言建模在内的目标学习双向上下文表示。二者都复用预训练结果，但可见上下文和训练目标不同，适用方式也随之不同。[Radford 等，2018](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf)，[Devlin 等，2018](https://arxiv.org/abs/1810.04805)。

GPT-3 进一步考察了另一种使用方式：在输入里放入任务说明或少量示例，然后直接生成结果。实验中的上下文学习没有为这些任务更新模型参数，因而有别于微调。[Brown 等，2020](https://arxiv.org/abs/2005.14165)。以情感分类为例，微调会用标注样本改变参数；上下文学习则把“句子—标签”的示例写入提示，让模型继续完成同样的格式。两者都可能改善任务表现，但成本、持久性和失效方式不同。

这组研究把语言建模的意义从一个独立任务扩展到了可复用的训练基础。与此同时，预测目标与使用目标之间的差异也变得更突出。一段常见、连贯的续写可能包含错误事实；在预测损失上取得进步，也不能直接证明系统已经能可靠完成用户交付的工作。

## 上下文计算：从压缩序列到选择相关信息

有了训练目标，模型还需要一种有效使用上下文的结构。循环网络逐步读取序列，把历史信息保存在不断更新的状态中。Sutskever 等人的序列到序列模型用编码器读取输入，再由解码器生成输出。[Sutskever 等，2014](https://arxiv.org/abs/1409.3215)。对于翻译任务，这种结构允许输入和输出具有不同长度，但也要求固定长度的表示保存生成所需的信息。

注意力改变了信息访问方式。Bahdanau 等人的翻译模型在生成每个目标词时，对源序列的不同位置分配权重，从中组合当前需要的信息。[Bahdanau 等，2014/2015](https://arxiv.org/abs/1409.0473)。译到句尾时，模型仍能访问句首的表示，不必只依赖一个最终压缩结果。这里的“注意”是一种可学习的加权运算。

Transformer 进一步以注意力组织序列计算，原始结构包含编码器和解码器。[Vaswani 等，2017](https://arxiv.org/abs/1706.03762)。自注意力让同一序列中的位置相互获取信息：输入被投影为查询 Q、键 K 和值 V，Q 与 K 的[点积](/concepts/dot-product/)给出匹配分数，缩放后经 [Softmax](/concepts/softmax/)形成组合 V 的权重。自回归模型还需要因果掩码，避免在预测时读取未来 token；位置处理、前馈层、残差连接和归一化共同组成完整架构。

比较这些方法，可以看到两个相关但不同的收益：注意力改善了访问信息的路径，Transformer 则让训练中的序列计算更适合并行组织。它们帮助模型利用上下文，也改善了扩大训练的计算条件。代价同样具体：标准全注意力需要处理随序列长度平方增长的位置关系，自回归生成通常仍然逐个产生 token。详细机制将在[自注意力](/concepts/self-attention/)一章展开。

## 规模化的条件：数据、硬件与训练预算

仅从模型结构出发，仍然难以解释大模型为什么能在实践中训练出来。数据能否获得、能否整理，以及计算能否负担，都会改变一个算法的实际价值。

互联网与万维网承担了不同的角色。前者通过分组交换和通信协议连接计算机，后者在网络上用地址、超文本和访问协议组织文档。ARPANET 的发展与 TCP/IP 的采用形成了互联基础；CERN 的万维网工作则推动了文档发布、链接和访问。[Leiner 等，互联网史回顾](https://www.internetsociety.org/resources/doc/2017/brief-history-internet/)，[CERN，万维网历史](https://home.cern/science/computing/the-birth-of-the-web/)。由此积累的数字内容扩大了可用语料，但原始网页与训练数据集之间还有很长一段处理过程。

MapReduce 研究的是怎样在集群上组织大规模数据处理，ImageNet 展示的则是如何收集和组织大规模标注图像。它们分别体现了处理能力与数据组织的重要性。[Dean 与 Ghemawat，2004](https://research.google/pubs/mapreduce-simplified-data-processing-on-large-clusters/)，[Deng 等，2009](https://www-cs.stanford.edu/groups/vision/pdf/ImageNet_CVPR2009.pdf)。把工作分给多个节点，并不会自动提高数据质量；重复内容、错误标签和不均衡的覆盖，仍要在数据管线中处理。

AlexNet 在 ImageNet 上的结果提供了一个具体案例：深度卷积网络、大规模标注数据和 GPU 计算结合后，取得了显著的图像分类效果。[Krizhevsky 等，2012](https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks)。卷积利用图像局部结构，GPU 支持大量并行数值运算。这项结果支持了深层表示学习的实用价值，但卷积架构本身无法解释语言模型的全部发展。更有启发的是，算法、数据与硬件必须一起考虑。

规模化研究把这种关系变成了可测量的资源配置问题。Kaplan 等人研究参数量、数据量和计算量与语言模型损失之间的经验关系；Hoffmann 等人的 Chinchilla 工作进一步指出，在固定计算预算下，参数规模与训练数据量需要配合增长。[Kaplan 等，2020](https://arxiv.org/abs/2001.08361)，[Hoffmann 等，2022](https://arxiv.org/abs/2203.15556)。给定预算，扩大模型并不总是最好的分配方式，还要考虑它能接受多少训练数据。

这些结果为训练规划提供了依据，其外推范围仍受实验条件约束。较低的语言预测损失、多项任务上的更好表现、以及部署后的成本收益，需要分别评估。把它们统称为“模型更强”，会丢掉重要的区别。

大语言模型通常指在大规模文本及相关数据上训练、具有较大参数规模的语言模型，没有永久适用的参数门槛。“基础模型”则强调广泛训练后适应多种下游任务的复用方式。[Bommasani 等，2021](https://arxiv.org/abs/2108.07258)。这一区分有助于理解规模的意义：值得关注的是计算投入获得了哪些可复用能力，以及在具体任务中还需要付出多少适配成本。

## 从模型到 Agent：评价对象发生了什么变化

预训练模型学会预测文本后，还需要适应用户提出请求的场景。InstructGPT 使用示范数据、偏好比较和基于人类反馈的强化学习，改善模型遵循指令的表现。[Ouyang 等，2022](https://arxiv.org/abs/2203.02155)。这类后续训练改变了模型倾向生成什么，却不能保证每次回答都有事实依据。用户喜欢的回答与可核实的回答，也需要分别检查。

获取外部信息是另一项工作。检索增强生成（RAG）将检索材料交给生成模型，使回答可以利用参数之外的记录。[Lewis 等，2020](https://arxiv.org/abs/2005.11401)。参数中学到的信息、当前上下文和外部资料承担不同角色：参数提供训练所得的能力，上下文承载当前任务，外部资料提供可按需取用的证据。检索是否找到正确材料、生成是否忠实使用材料，都影响最终结果。

如果任务还要求修改文件或执行查询，就需要把输出连接到行动。ReAct 探索了推理与行动交替进行的组织方式。[Yao 等，2022](https://arxiv.org/abs/2210.03629)。它是语言模型参与 Agent 系统的一条路线；Agent 研究本身则早于大语言模型。这里最直接的变化是：评价不能停在生成的文本上，还要检查环境中实际发生了什么。

假设用户要求修复一处程序错误。模型可以给出看似合理的补丁，但任务是否完成，要看文件是否写入、相关测试是否通过，以及修改有没有引入新的问题。工具返回失败时，系统还必须决定重试、调整方案或停止。模型生成请求，运行时负责校验参数、检查权限、执行操作并记录结果。[工具调用](/concepts/tool-calling/)与 [Agent 循环](/concepts/agent-loop/)分别讨论这一边界和多步执行过程。

由此也能看清不同评测的用途。预测损失检查语言建模目标，任务指标衡量某类能力，系统评测则检查执行结果、代价与失败恢复。前两者可以为系统设计提供证据，最终仍需要在实际任务上验证整个流程。

## 讨论与结语

把这些研究放在一起，本文更倾向于用几个问题之间的相互制约来解释大模型。可计算性提供形式基础，学习方法决定怎样从经验调整行为，表示与架构决定哪些关系容易被利用，数据和硬件则限制了这些方法能被训练到什么程度。预训练把投入转化为可在任务间复用的参数；上下文学习和后续适配又改变了人们使用这些参数的方式。这是对所选文献的综合解释，并不意味着各条研究路线只能走向同一种模型。

仍有两个问题需要保留。其一，语言预测成绩与具体能力之间的关系，要通过细分任务和失败案例来研究，单一指标不足以说明全部表现。其二，模型在文本中表现出的能力，怎样才能转化为环境中的可靠行动，需要系统层面的验证。扩大训练与改进运行时解决的是不同部分，工程实践必须同时面对它们。

后续章节可以沿这些问题深入。理解表示变换，需要向量、矩阵和点积；理解预测与注意力权重，需要概率分布和 Softmax；理解模型如何参与多步工作，则需要工具调用与 Agent 循环。沿前置知识展开局部推导，才能逐步判断一次能力提升究竟来自哪里，又在哪些条件下会失效。
